# Kids Drawing App 🎨

این یک پروژه‌ی ساده‌ی اندروید است که امکان نقاشی کردن روی صفحه را فراهم می‌کند.  
این پروژه فقط با **گوشی** ساخته شده و تمام فایل‌ها به صورت دستی در GitHub قرار گرفته‌اند.

## امکانات:
- نقاشی با لمس صفحه
- انتخاب رنگ (قرمز و آبی)
- پاک کردن صفحه
- طراحی ساده و مناسب برای کودکان

## ساختار پروژه:
- `MainActivity.kt` کنترل دکمه‌ها و صفحه اصلی
- `DrawingView.kt` بخش اصلی نقاشی
- `activity_main.xml` رابط کاربری
- فایل‌های Gradle برای تنظیمات پروژه
- `AndroidManifest.xml` برای معرفی Activity اصلی

## هدف پروژه:
ساخت یک اپ نقاشی ساده برای کودکان، بدون استفاده از اندروید استودیو، فقط با گوشی و GitHub.
